# Suivi Projets

Application de suivi de projets clients — refonte pixel-perfect d'un design existant.

## Stack

- React 19 + TypeScript
- Vite 7
- Tailwind CSS 4
- Chart.js 5 + react-chartjs-2
- lucide-react

## Lancer localement

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
```
